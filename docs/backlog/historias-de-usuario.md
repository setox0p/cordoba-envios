# Historias de Usuario - Córdoba Envíos

## HU-01: Registrar un envío

Como empleado de recepción, quiero registrar los datos del remitente, destinatario y paquete para generar un envío del sistema.

**Criterios de aceptación:**
- El sistema debe solicitar los datos del remitente.
- El sistema debe registrar los datos del destinatario.
- El sistema debe permitir cargar las características del paquete.
- El sistema debe generar un número de seguimiento único.

**Estado:** Por Hacer

## HU-02: Consultar el estado de un envío

Como cliente, quiero consultar el estado de mi envío para conocer su ubicación y situación actual.

**Criterios de aceptación:**
- El sistema debe permitir buscar por número de seguimiento.
- Debe mostrar el estado actualizado.
- Debe informar la fecha del último movimiento.

**Estado:** En Progreso

## HU-03: Registrar la entrega

Como empleado de logística, quiero registrar la entrega del paquete para dejar constancia de su recepción.

**Criterios de aceptación:**
- El sistema debe permitir confirmar la entrega.
- Debe registrar fecha y hora.
- Debe identificar a quien recibe el paquete.
- Debe actualizar el estado del envío a Entregado.

**Estado:** Listo
